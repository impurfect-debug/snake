Snake 🐍

A simple Snake game developed in Python with the Pygame library.

About the Game:

Snake is a small interactive game where players control a snake, collect food, and try to achieve the highest possible score.

Features:

- Interactive game window
- Score displayed in the terminal
- Keyboard controls
- Simple gameplay

Requirements:

- Python 3
- Pygame

Installation

Install Pygame:

pip install pygame

How to Run?

Run the game using:

python main.py
